# Superstore-Sales-Dashboard
Superstore Sales Analysis Using Power BI

Superstore Sales Dashboard | Power BI

Project Overview

The Superstore Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI. It analyzes sales, profit, orders, and product performance to provide meaningful business insights. The dashboard helps users understand sales trends and evaluate business performance through clear and interactive visualizations.

Project Objectives

- Analyze overall sales and profit performance.
- Compare sales across product categories and regions.
- Understand monthly sales trends.
- Identify high-performing products and sub-categories.
- Create an interactive dashboard for business analysis.

Tools and Technologies

- Microsoft Power BI
- Power Query
- Microsoft Excel / CSV

Data Cleaning and Preparation

The dataset was imported into Power BI and prepared using Power Query. Data types were checked, and missing values, duplicates, and formatting issues were reviewed to improve data quality before creating visualizations.

Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold

Dashboard Features

- Category-wise and sub-category-wise sales analysis.
- Region-wise sales and profit comparison.
- Monthly sales trend analysis.
- Product performance analysis.
- Interactive slicers and filters.
- KPI cards for quick performance monitoring.

Key Insights

The dashboard helps explore sales trends, compare regional performance, identify profitable categories, and understand product performance. The findings can support business planning and data-driven decision-making.

Conclusion

This project demonstrates practical skills in data cleaning, data visualization, and business intelligence using Power BI. It converts raw sales data into an interactive dashboard that makes important business metrics easier to analyze and understand.

Future Scope

The dashboard can be enhanced with sales forecasting, customer segmentation, detailed profitability analysis, and regularly updated data for more advanced business reporting.
